# 🚀 Howest Blender (v5.2 Update)

Welcome to our custom Blender build! This repository provides a pre-configured version of Blender tailored specifically for high-efficiency visualization and industrial design workflows.

![](screenshot.png)

## 📥 Download Recommendation
While vanilla Blender is available via the official website, we strongly recommend downloading **this Howest version**. It comes pre-configured with industry-standard settings, essential extensions enabled, integrated remote asset access, and a custom **visualisation template** designed to remove interface clutter and streamline your workflow.

---

## ✨ Key Features
* **Native Remote Asset Libraries:** Instant access to online cloud asset libraries directly inside the Asset Browser.
* **Integrated ambientCG Search:** Search, preview, and stream thousands of CC0 PBR materials, HDRIs, and models directly from ambientCG without manual downloading or unpacking.
* **Pre-loaded Local Materials:** Instant drag-and-drop workflow for standard plastics, metals, woods, and glasses—just like KeyShot.
* **Clean Interface:** Our custom template clears out redundant workspace clutter, camera defaults, and viewport panels for a focused product visualization setup.
* **Optimized Render Defaults:** Configured out of the box for fast viewport previews and efficient Cycles/EEVEE production rendering.
* **Ready-to-Go Extensions:** Essential tools and node setups pre-activated with no configuration needed.

---

## 🛠 Installation & Usage
1. **Download** the latest Blender 5.2 release package from the [Releases](../../releases) page.
2. **Extract/Run** the installer and choose your preferred local destination (e.g., `C:/Blender_Viz`).
3. **Launch** Blender and select the **Visualisation** template from the splash screen (or navigate to **File** → **New** → **Visualisation**).
4. **Access Remote Assets:** Open the **Asset Browser** editor, switch the library dropdown to **ambientCG** or **Online Essentials**, and drag materials directly onto your model.
